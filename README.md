# MWEAI

Creo 插件，原名 BWTL。[本次品牌升级和回退方法](docs/MWEAI品牌升级与回退.md)

Codex 可按会话连接本机 Creo，通过 MWEAI 原生功能读取和修改模型。见 [MWEAI 本机控制](docs/BWTL%20本机控制.md)。

MWEAI 三路连接可在同一 Creo 会话中结合常驻事件、Creo VB API 窗口操作，以及已绑定的原生建模命令。用法见 [MWEAI 三路连接](docs/BWTL%20三路连接.md)。

三路连接版可以从现有 Creo 入口随 MWEAI 启动。每个进程加载后可在本机客户端 `Status` 核对连接状态。

MWEAI 可从当前原生骨架取尺寸，重画带孔槽的矩形钣金平板，并在总装、子装配和零件窗口查看干涉红框。用法见 [参考建模与装配](docs/BWTL%20参考建模与装配.md)、[装配批量图号](docs/BWTL%20装配批量图号.md)和[两份 Creo 分享功能对照](docs/两份Creo分享功能对照.md)。

聊天中发送「把装配经验写入建模规则」可保存最近讨论的装配方法，保存后返回 E 盘文件路径。见 [建模规则](docs/BWTL%20建模规则.md)。

「标准文件 → 建模规则」可查看、修改和恢复共享规则。「创建新零件」直接执行公司流程。见 [MWEAI 建模规则](docs/BWTL%20建模规则.md)。

顶部「标准文件 → 紧固件」侧栏列出 8 个分类，点击箭头即可展开型号与已有中文说明。 聊天中可以按型号查找、读取或打开本机标准紧固件。见 [标准文件与紧固件](docs/BWTL%20标准文件与紧固件.md)。

MWEAI 支持从子零件或子装配窗口回到已核对的装配。见 [回到装配](docs/BWTL%20回到装配.md)。

MWEAI 的操作授权、会话隔离、E 盘数据、回退和交付要求见 [安全与授权边界](docs/安全与授权边界.md)。

MWEAI 支持钣金平板居中四孔、逐项加工反馈和同一模型的任务续接。见 [钣金四孔与失败续做](docs/BWTL%20钣金四孔与失败续做.md)。

在 MWEAI 发送「创建一个零件」，可带图号和版本，自动建空装配、按默认定位装入同号空钣金件并打开子件。见 [创建同号钣金零件](docs/BWTL%20创建同号钣金零件.md)。

MWEAI 支持从 Creo 装配树打开子零件或子装配的独立窗口。见 [打开装配组件](docs/BWTL%20打开装配组件.md)。

MWEAI 聊天支持查公司资料、读取库模型、按已核对的来源装配，以及在数据盘项目目录输出模型和图纸。见 [公司资料与设计](docs/BWTL%20公司资料与设计.md)。

MWEAI 聊天支持添加 PDF、Creo 文件、图片和文本分析。见 [聊天附件分析](docs/BWTL%20聊天附件分析.md)。

MWEAI 新增指令运行计时：右上角实时计时，结束或停止后显示总用时。详见 [指令计时](docs/BWTL%20指令计时.md)。

# 霸威天龙 v21.2 / 0.21.2-preview.1

Creo Parametric 10.0.0.0内的Windows原生AI助手，通过进程内Pro/TOOLKIT执行操作，不使用浏览器、MCP或截图键鼠模拟。

## 便捷安装

1. 双击 `BWTL-Setup-0.21.2-preview.1.exe`，选择安装目录和Creo实际读取的config.pro。
2. 由安装器配置注册和本机数据路径。完整作者聊天、记忆和功能索引在首次安装导入，升级保留安装者自己的记录。
3. 本机需准备Creo10、x64 C++运行库及可用的Codex登录环境。安装包不包含Creo、PTC SDK、公司模板和登录凭据。
4. 保存Creo工作后重启，首次按Creo提示允许插件。顶部点击“霸威天龙”，或在图形区依次按 c、d、x 打开霸威天龙 v21.2。
5. 先读取模型，再按功能说明在测试零件操作。更新支持版本并存、升级备份和回退，不自动关闭用户Creo。

详细步骤：[安装与数据迁移](docs/v20安装与数据迁移.md)。发行文件在dist；GitHub是否已有该版本以实际Release为准。

## 一键卸载

开始菜单选择“卸载霸威天龙”，或双击安装目录BWTL-Uninstall.exe。可分别选择删除程序文件和数据文件，默认保留聊天/记忆。详见[新版安装与卸载](docs/v21.1一键安装与卸载.md)。

## 功能与限制

保留此前聊天、记忆、模板空模型、基础造型、参数/尺寸和01—10工具。新增11—15：编辑独立关联草绘、真实关联投影、首个/已有单实体标准拉伸加料、定深/贯穿切除、旋转加料。

新增写入限独立普通单实体零件。自动装配、钣金专用建模、旋转切除及二维工程图尚未接通。不自动保存，不把有限测试说成任意模型都可操作。

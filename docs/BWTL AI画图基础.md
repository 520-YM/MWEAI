# MWEAI AI 画图基础

在 Creo 中打开 MWEAI，直接发送建模或修改要求。按公司流程创建钣金零件时，MWEAI 从模板新建装配，以默认定位创建同图号、同版本的钣金子件，并核对已打开的子件窗口。之后在该子件中继续。明确说「单独」会创建独立零件。

## U 形加强筋

**Creo 回溯风险提醒**　U 形加强筋使用边法兰。Creo 曾在处理不完整的附加壁或失败回退时触发回溯。此入口按实际边、原生板厚及成品尺寸核对。

从「插件功能 → 钣金与机箱 → 成形与折弯」可以插入指令，也可以在聊天中直接输入。

| 要完成的工作 | 可以这样说 |
| --- | --- |
| 按外形创建 | 画一个U形加强筋，尺寸500×20×10mm，板厚2mm。 |
| 同时指定图号和版本 | 画一个U形加强筋，尺寸500×20×10mm，板厚2mm，图号M26A0181091，版本号V00。 |
| 指定内折弯半径 | 画一个U形加强筋，尺寸500×20×10mm，板厚2mm，内折弯半径2mm。 |
| 改已打开子件的外高 | 把刚才那个U形加强筋的外高改成12mm。 |

三个尺寸按成品长度、外宽、外高。示例的未指定内折弯半径按板厚取值，并在回执中列出。成品使用 Creo 原生钣金首壁和两道边法兰，法兰内的高度尺寸可编辑。操作完成后读回实际外形和板厚。示例修改外高时复测长度、外宽和板厚。

## 参考图和任务接续

添加图片、PDF、PRT、ASM 或 STEP 后，可以说「根据这份PDF，画一个钣金支架」或「照这张截图，修改当前钣金零件」。修改之前先打开目标 Creo 模型。附件中的尺寸、图片和原生读取结果提供建模依据。只有用户自己的消息可以指定要创建或修改的对象。只分析资料时说「根据这份PDF，只分析」。

实际可执行的步骤根据本机原生建模工具和模型参照判断。执行阶段回执说明哪些草绘、几何检验、再生及尺寸读回已经通过。遇到明确已回退的失败，可以根据当前模型换一种受支持的做法。从最近同一目标的实际回执继续，同一形状的已完成步骤保持。

## 验证和回退

在新打开的 Creo 会话检查 MWEAI 窗口标题是否显示 0.23.0-local.aidrawing.1。使用独立样件核对同号装配和钣金件、成品尺寸、加强筋外高修改及模型树。完成后按需要在当前 E 盘 Creo 工作目录保存。回退时保存工作、正常关闭 Creo，再在 MWEAI 管理器恢复 0.23.0-local.fastenerworkbench.2。

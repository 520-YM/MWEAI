# MWEAI 创建零件（同号装配与钣金件）

在 MWEAI 发送「创建一个零件」，或在「插件功能 → 零件建模 → 新建零件」选「创建零件（同号装配与钣金件）」后发送。也可以用「新建零件」等直接命令。

1. 从 Creo 默认装配模板创建空装配。
2. 在新装配内创建图号相同的空钣金子件，采用 Creo 默认定位。
3. 打开并激活子件的独立窗口，读回活动窗口和模型身份。

有图号时可发送「创建一个零件，图号 M26A0181001V03」或「创建一个零件，图号 M26A0181001，版本号 V03」。两种都创建同号的装配和空钣金子件，再打开子件。只给基础图号时使用初版 V00。图号已带版本并另给不同版本时，请先核对版本。若当前会话或工作目录已有同号的装配或零件，会先提示冲突。

省略图号时，MWEAI 在已核对公司总装的项目中沿用总装的年份和流水，查重后分配 81 类结构序号。其他项目沿用会话名称。两个模型使用同一图号和版本，分别用于 `.ASM` 和 `.PRT`。三个步骤均核实后，聊天才会给出一条完成回执。失败时会指出卡住的步骤，保留在会话中已完成的模型。Creo 复制模板产生的初始文件放在本会话的 E 盘暂存目录。需要写入完整装配关系时，在 Creo 中保存装配。显式命令「创建实体空零件」「新建钣金空零件」仍可单独创建对应模板的零件。

升级到 0.23.0-local.continuity.1 后，下一次正常打开 Creo 即可使用。原生验收、图号接续与回退方式见《MWEAI 任务接续与恢复》。

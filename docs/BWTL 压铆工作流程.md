# MWEAI 压铆工作流程

打开实际装配，先把 Creo 工作目录切到 E 盘项目。聊天里发「列出压铆板件」查看活动顶层钣金实例，重复零件会按实例 ID 区分。本页的 ID、组名和孔号都是示例，使用时替换成当前 Creo 的回读值。

| 功能 | 聊天示例和行为 |
| --- | --- |
| 1. 直接选孔 | 在 Creo 中选中圆柱孔壁或圆形孔口边，发送「给选中的孔分组：左组 装 BSO M3×6」。一次选一个顶层安装板。 |
| 2. 截图圈选 | 在装配截图改图窗口圈选并输入「选择这些孔用于压铆分组」。回到主聊天发送「给截图孔分组：左组 装 BSO M3×6」。标注先映射并高亮真实 Creo 孔位。 |
| 3. 区分板件实例 | 「板件 ID:42 查看可装配孔位」或「板件 ID:42 分组装配：左组 1、4号孔 装 BSO M3×6」。在有多个同名板件时，用同一 ID 继续查看、补装或改组。 |
| 4. 按孔径选孔 | 「板件 ID:42 按孔径分组：Ø5.4 排除 2号孔；左组 装 BSO M3×6」。 |
| 5. 编辑分组 | 「编辑压铆组：改名 左组 新组」「编辑压铆组：合并 左组 到 右组」「编辑压铆组：拆分 左组 4号孔 到 中间组」「编辑压铆组：加入 左组 7号孔」「编辑压铆组：移出 左组 4号孔」。移出和拆组只调整登记关系，孔内件保留。加入会按已有组规格装配。 |
| 6. 使用其他公司压铆件 | 「分组装配：左组 1号孔 装 型号 B_MX_X:B-M4-1」。采用公司库中确切的族表与实例或独立文件名，可覆盖已有原生放置支持的压铆螺母、螺钉、定位销。 |
| 7. 按实际孔推荐 | 「推荐压铆件：1号孔 M4 压铆螺母」。按实测孔径、板厚和公司库可核对资料给结果。 |
| 8. 指定安装侧 | 「板件 ID:42 反面 分组装配：左组 1号孔 装 BSO M3×8」或用「安装面 SURFACE:160」。先用指定侧的「查看可装配孔位」核对该孔可用。 |
| 9. 顺序装配 | 「顺序装配｜分组装配：左组 1、4号孔 装 BSO M3×6｜ASM_PCB_MOUNT …｜GROUP_SCREW_STACK …」。电子件按原生 PCB 参照装入，装配孔、贴合面、紧固件和最小插入深度需要精确参照。 |
| 10. 查找替代规格 | 「替代压铆规格：1号孔 BSO M3×8」。根据已登记公司库证据筛选同类可用实例，再明确选择规格。 |
| 11. 装前预检 | 「板件 ID:42 预检 分组装配：左组 1、4号孔 装 BSO M3×6」。预检不会写组、放置组件或保存模型。 |
| 12. 装后检查 | 「板件 ID:42 检查压铆分组 左组」。逐孔读取规格、同轴、贴合和实体间隙。 |
| 13. 只补漏装 | 「板件 ID:42 补装压铆分组 左组，保存到当前项目」。对已装实例读回后只补空孔。 |
| 14. 中断后续做 | 「板件 ID:42 恢复分组装配 左组」。重新核对源模型、孔位及已完成的实例，就同一个待办规格续做。 |
| 15. 检查改板影响 | 「板件 ID:42 检查改板影响」。列出原孔的移动、孔径或孔深变化以及无法找到的圆孔参照。 |
| 16. 保存及复用工艺 | 「保存压铆工艺：左组 门板工艺组」，新板上发送「复用压铆工艺：门板工艺组 左组 1、4号孔」。按孔径、板厚、安装侧及精确型号校验后复用。 |
| 17. 镜像复用 | 「板件 ID:42 镜像压铆组：左组 到 ID:60 右组 X=150，保存到当前项目」。X、Y 或 Z 指总装坐标平面，单位 mm；目标孔口与方向须一一对应。 |
| 18. PDF 核对 | 附上一份 PDF，再发「板件 ID:42 核对PDF孔位表」。表头为 PANEL X Y Z D GROUP SPEC，PANEL 是板件实例 ID，坐标、孔径以 mm 计。逐项匹配 Creo 孔位后给出实际结果。字迹不清或识别有歧义的行会提示复核。 |
| 19. 导出材料表 | 「板件 ID:42 导出压铆材料表」。按已装实例与分组生成 E 盘项目的材料清单和孔位表。 |
| 20. 导出检查截图 | 「板件 ID:42 标注压铆检查截图」。在当前 Creo 视图上投影孔号及状态并生成检查图。 |

模型修改只有在指令最后明确写「保存到当前项目」时才触发总装保存。另存的库件和分组记录在工作流程中按实际核对写入 E 盘。本机控制可用 Invoke-BWTL.ps1 的 PressfitWorkspace 操作，先用 Status 读取会话 context。

「顺序装配」支持带根装配名的 ASM_PCB_MOUNT。已核对压铆组的第 N 个实例可以写 GROUP:左组:N。紧固件阶段使用 ASM_FASTENER_STACK 或 GROUP_SCREW_STACK。GROUP_SCREW_STACK 的字段顺序为总装、%PCB%、PCB 孔壁、PCB 正面、PCB 背面、柱实例、柱孔壁、柱接触面、螺钉模型、杆面、承压面、垫圈模型、孔壁、底面、顶面、最小插入深度。所有面都从实际 Creo 模型读取。

**历史 Creo 回溯风险**　旧组件的连续替换及重定义曾触发 Creo 回溯。涉及旧实例替换时先检查下游依赖，写入 E 盘恢复副本，再逐孔替换与读回。试装只核对 Creo 定位及间隙。制造适配仍以实际公司工艺数据为准。

本机版本回退前先保存并关闭对应 Creo 会话，再从 MWEAI 管理界面恢复 0.23.0-local.groupedpressfit.1。原有单板分组文件可继续用新版本读取。多板按实例新增的记录存放在对应 MWEAI 的压铆任务目录。
## 螺钉直接旋入柱孔

顺序装配中的 GROUP_SCREW_STACK 使用本流程。PCB 已经定位时，也可以发「螺钉旋入柱孔｜GROUP_SCREW_STACK …，保存到当前项目」。独立执行时用实际 PCB 实例 ID 代替 %PCB%。最低插入参数按有效螺纹啮合长度核对，单位 mm。

柱孔优先读所选孔壁的 Creo 原生 ISO 攻牙规格和深度。供应商的简化模型可用实际圆柱所属特征上的 BWTL_THREAD_SPEC（例如 ISO M3x0.5 RH）、BWTL_THREAD_SURFACE_ID、BWTL_THREAD_FROM_MM、BWTL_THREAD_LENGTH_MM。两个长度是相对于当前指定承压面或柱孔入口的实测数据，均为毫米。用户输入的型号和圆柱直径不足以证明螺距。

螺钉与垫圈使用可回读的同轴和端面贴合约束。回执分别列出规格、几何旋入、有效啮合、距孔底的余量和定位误差。原生螺纹的简化实体只在对应有效啮合范围验算重叠。此验收为 CAD 装配，实际加工及承载以配套件资料和工艺验证为准。

回退此项时，保存当前工作并正常退出对应 Creo 会话后，从本机 MWEAI 管理功能恢复 0.23.0-local.pressfitworkspace.1。

# MWEAI 回到装配

在子零件或子装配的独立 Creo 窗口中，在 MWEAI 说「回到装配」「返回父装配」或「放回到装配体」。也可从「插件功能 → 装配与定位 → 命名与建件」选择「回到装配」。

MWEAI 优先回到打开当前组件时的原装配窗口，并核对该窗口实际包含当前组件。若从其他入口打开子件，则在本 Creo 进程已打开的窗口中按实际组件身份查找所属装配。同一层级有多个候选时会列出装配名称，可指定「回到装配 M26A0181001V00.ASM」。

这是窗口切换。父装配和子件留在同一 Creo 会话，已有几何与待保存改动保留。收到 Creo 的活动窗口和模型读回后，聊天才报告已回到装配。

本机从 0.23.0-local.chatrepair.1 升级到 0.23.0-local.returnasm.1。保存工作后正常重启 Creo 即可使用。需要回退时，通过 MWEAI 管理功能恢复 0.23.0-local.chatrepair.1，再正常重启。


## 按型号切换和读取装配树

发送「读取会话模型与窗口清单」可查看当前 Creo 进程中的模型名、PRT/ASM 类型、窗口 ID 及当前活动项。发送「回到装配 AI_ASM_261119_133845_1V00.ASM，然后读取装配树」可切到该装配。已加载的模型尚无窗口时会打开独立窗口。宿主确认模型、窗口和工作目录后才更新本轮任务目标。原窗口及未保存改动会保留。多装配或同名零件、装配并存时，建议使用带扩展名的完整模型名或指定窗口 ID。

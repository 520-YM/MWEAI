# MWEAI 建模规则

在「标准文件 → 建模规则」查看生效流程、默认图号版本、上一次变更和规则文件位置。「修改规则」与「恢复上一版」会把命令填进空白输入框，发送才生效。也可以直接在聊天里发送以下指令。

| 需求 | 示例 |
| --- | --- |
| 看当前流程和版本 | 查看建模规则 |
| 改默认图号版本 | 写入建模规则：默认版本 V07 |
| 登记公司流程 | 写入建模规则：默认流程 公司 |
| 恢复先前配置 | 恢复上一版建模规则 |
| 记录上一条已识别的流程 | 把这条写入 MWEAI |

可执行设置包含创建流程和默认图号版本。恢复一次会将被替换的设置保留为上一版。规则只接受用户在本机明确发送的命令。讨论、已有聊天、附件和模型回执提供参考。现有的「记住：内容」可继续保存一般背景和偏好。

本机规则文件为 E:\BWTL-Data\AppData\Local\BWTL\data\建模规则.bwtl。受管理的 8 个 MWEAI 实例共享此规则。每次执行时读取生效版，各实例的聊天记录和 Creo 模型任务独立。首次使用初始化公司流程与 V00，其他安装沿用安装时选定的数据盘。

## 创建零件

- 「创建新零件，图号 M26A0181001，版本 V03」新建同图号、同版本的 ASM 和 PRT。 Creo 在新装配内默认定位装入空钣金件，之后打开并核对钣金件窗口。提供完整图号时沿用显式版本号。省略图号时，先检查同一项目已核对的公司总装图号，再确定可用的结构序号。普通项目沿用会话名称。
- 「单独创建一个零件」创建独立空零件。需要独立空钣金件时可说「单独创建一个空钣金零件」。
- 「创建新零件，图号 M26A0181001V04，不要单独建」仍按公司流程。指定「在当前装配里建子件」时使用该装配。
- 每次完成时查看最终一条回执。若报告已完成前几步且可以继续，可发送「继续创建零件」。插件重新核对同一 Creo 会话、工作目录与已创建对象，再从已确认的步骤继续。模型留在当前会话。Creo 复制空白模板时产生的缓存放在该 MWEAI 会话的 E 盘数据目录，复制后恢复项目工作目录。项目文件在明确保存时写入。

## 验证和回退

保存当前工程工作后正常重启 Creo，再通过「标准文件 → 建模规则」查看。可在 E 盘独立测试目录验证同图号子件和默认定位。需要回退插件时在 MWEAI 版本管理中恢复 0.23.0-local.fastenercatalog.1，再正常重启。规则文件保留在 E 盘，可继续用于以后版本。


## 保存装配经验

在讨论并确定装配方法后发送「把装配经验写入建模规则」，插件保存本会话最近一条助手回复中的装配内容。也可直接发送「把装配经验写入建模规则：具体经验内容」。保存后读回文件核对，并在一条回复中返回结果和完整路径。

文件按条保存在主实例 data\建模规则\装配经验 下，UTF-8 文本，每次创建新文件。受管理的其他实例共享这些条目。发送「查看装配经验规则」可查看条数、目录和最近内容；「查看建模规则」也显示条数。后续装配请求自动读取最近 12 条保存记录，每条最多提供 1600 字，作为用户经验参考；实际定位仍需要核对当前组件、孔轴和安装面。

例如可保存「连续建模与装配的故障续做」作为装配经验，记录何时更新目标、检查回退及从已完成步骤继续。插件也会独立校验实际 Creo 窗口、实例路径和工作目录。

保存记录包括来源和时间。对话中的方法说明按经验记录保存，其验证情况以原内容和原生回执为准。当前会话没有可识别的装配内容时，插件提示补充具体内容。新对话清除待保存的上下文，E 盘已经保存的文件继续保留。

## 保存通用建模规则

在聊天中直接说「把这条写入 MWEAI 建模规则：每次建模前核对生效规则。遇到失败时保留已完成步骤，结合实际回执尝试可用的替代方法。」也可以在明确上下文后说「把刚才确认的做法写进建模规则」。MWEAI 将授权保存的正文写到数据目录的 `建模规则\装配经验`，读回核对后返回文件完整路径。近期通用规则在新会话组装建模上下文时自动载入。默认建零件流程和图号版本仍由专用规则编辑入口管理。

可发送「查看装配经验规则」核对保存记录。若需要撤回单条通用规则，可将该回执指向的规则文件移出规则目录并保留副本。新任务会按目录中实际存在的规则组装上下文。

先说明要保存什么，再直接提出写入要求也可以。例如「这是刚确认的定位方式，你把这个方式写入 MWEAI 建模规则里面去」。MWEAI 从对话取得被指代的内容，按用户明确指定的规则目标保存。引用示例、询问和明确取消写入的消息不触发保存。


## 圆孔网格

等径圆孔规则直排或交错时，按实际板厚、加工面和定位参照使用 VENT_ROUND 一次加工。详见《MWEAI VENT_ROUND 建模规则》。已登记的本机规则随 E 盘主实例的建模规则载入。

# MWEAI 标准文件与紧固件

顶部「标准文件」菜单包含「打开已验收标准件」「紧固件」「建模规则」「资料」和「归档」。打开「紧固件」后，侧栏先列出 8 个分类。

| 分类 | 内容 |
| --- | --- |
| 螺丝装配 | 沉头、扁圆头、内外六角等螺丝及配套装配 |
| 螺栓 | 螺栓与马车螺丝 |
| 螺母 | 六角、方形、法兰、蝶形与滚花等螺母 |
| 销 | 销类 |
| 压铆件 | 压铆螺丝、盲孔与通孔压铆螺母、铜柱等 |
| 铆钉 | 铆钉类 |
| 自攻螺丝 | 自攻螺丝、大扁圆头螺丝与异形螺丝 |
| 垫圈 | 垫圈类 |

点击分类或右侧箭头即可在侧栏原位展开或收起。多个分类可同时展开，滚动查看 Creo 型号与已有中文说明。键盘可用方向键选择分类，向右方向键展开、向左方向键收起，Enter 或空格切换展开状态。相同目录中的同名模型只列一次，选中时使用数字修订最高的实际文件。族表中的规格实例随对应型号管理，清单以磁盘上的零件和装配模型为单位。

点击型号会在 Creo 中打开该紧固件，并把原生文件保存到当前工作目录，读回核对后回复实际文件路径。工作目录中的同名不同内容文件需要先确定处理方式；同内容文件可直接复用。装配型紧固件连同 Creo 备份生成的依赖文件一起复制。临时备份保留在 MWEAI 的 E 盘会话目录。MWEAI 先查本实例的分类，受管理的次实例缺少该分类时读取本机主 MWEAI 的对应分类。

聊天中可发送「查找紧固件 BSOS_3_5M3XX」「读取紧固件 BSOS_3_5M3XX」或「打开紧固件 BSOS_3_5M3XX」。自然说法「BSOS_3_5M3XX我要调这个出来」也可直接在活动 Creo 进程中打开。读取会回报模型信息，打开会确认实际活动窗口和源文件版本。限定范围是本机配置的 8 个紧固件分类及该分类下的模型，受管理的其他 MWEAI 实例沿用分类回退。型号唯一时使用该路径下数字修订最高的版本，有同名候选时可在菜单按分类选定。对已经在 Creo 里打开且有待保存修改的同名模型，先保留当前修改，再由用户确定是否需要换版本。

## BSO M3×5/M3×6 查找、另存和装配

聊天输入「查找 BSO M3×5」或「查找 BSO M3×6」读取标准库同一系列族表里的确切实例。M3×5 对应 `BSO-3_5M3X5`，M3×6 对应 `BSO_3_5M3X6`。MWEAI 核对族表身份和实际长度。连续讨论同系列装配时，「那你帮我装配 M3×5 的吧」会从本会话最近的明确 BSO 装配指令承接系列和孔数，仍核对当前模型的实际参照。输入「我要 BSO M3×6」或「另存 BSO M3×6」会从该实例另存原生独立零件到当前 E 盘 Creo 工作目录，文件基名为 `BSO_3_5M3X6_BWTL`。后缀区分项目独立件与库里的族表实例。源文件只读，已存在的项目件要通过原生几何核对才复用。

在目标装配中选择同一块钣金件的压铆接触面和 1–12 个 Ø5.4 圆孔孔壁，发送「装配 BSO M3×6 到选中的孔位」。孔数明确时，也可只选安装面并说「装配 6 个 BSO M3×5」，MWEAI 会核对该面的实际孔组和数量。安装方向由选中的接触面决定。MWEAI 按实际几何核对孔轴与承压面，逐孔写入同轴和端面重合约束，读回组件 ID、定位和再生状态。再次执行时，核对过的已装同规格组件会保留，继续处理尚未完成的孔。装配默认未保存。

发送「检查公司库访问」可在 Creo 中查看实际资料位置和压铆件分类。回执会区分授权范围、目录缺失、Windows 拒绝、占用或链接。调用资料工具时，「公司库」「公司标准库」等入口解析为 E 盘已登记的公司资料目录。受管理的次实例共用主库的读权限，菜单和聊天仍可按当前实例读取已登记的紧固件分类。明确提交的其他目录仍按用户授权范围检查。下次正常重开 Creo 后使用新版本，可用 MWEAI 管理器恢复上一版本。

本机曾从 0.23.0-local.fasteneraccordion.1 更新到 0.23.0-local.fastenerauth.1。正常重启 Creo 后，可以在聊天中用型号读取或打开，并通过回执核对文件名。需要回退时恢复 0.23.0-local.fasteneraccordion.1，再正常重启。


## 按型号装配压铆件

在 Creo 装配里，先选中钣金件的安装面，再按住 Ctrl 选需要装配的圆孔孔壁。选孔时，同一孔只选一个孔壁。也可只选安装面并明确数量，MWEAI 会在该面按孔径和接触条件查找，实际孔数与要求一致后才执行。

- 例如「装配 6 个压铆件 BSO M3×8 孔径5.4mm」「装配 2 个压铆件 S-M3-1 孔径4.22mm」「装配 3 个压铆件 FH_M3_XX:FH-M3-8 孔径3mm」。
- 用「核对压铆件 B-M3-1」查看库件的定位参照。对有多组装配参照的型号，可补充「定位面 SURFACE:136 贴合面 SURFACE:63」。具体面号以该库件回执为准。只想获取项目零件时，可说「另存压铆件 B-M3-1 到当前工作目录」。
- 标准库以准确型号、族表行和磁盘修订为准。型号重名时可用「族表名:实例名」区分。例如公司库中 FH 与 NFH 族表都有「FH-M3-8」。省略孔径时，常用 BSO 3.5 系列定位径 Ø5 mm 对应已验的 Ø5.4 mm 孔，其他库件默认按定位径核对。需要使用不同孔径时明确给出实际孔径，工艺允许过盈时可提供「允许过盈」及其最大直径差。
- MWEAI 将验实的型号另存在当前 E 盘 Creo 工作目录。装配时逐孔创建原生同轴、端面贴合约束，并回读型号、定位、安装方向、再生状态。再次执行会保留已经验证的同规格实例。需要落盘时按正常 Creo 保存装配。
- 验收包括 BSO M3×8 螺母柱、S-M3-1 通孔压铆螺母、B-M3-1 盲孔压铆螺母和 FH-M3-8 压铆螺柱。该批次实测为这四种规格。通用入口按各件的实际圆柱定位和承压面核对，其他规格和异形件按实际回执确认。
- 升级后在新开的独立 Creo 会话核对 MWEAI 版本和装配回执。需要回退时用 MWEAI 管理器恢复 0.23.0-local.fastenerflow.1，再正常重开 Creo。



## 逐规格实装验收

在「插件功能 → 阵列与紧固件」中选择「压铆件逐规格验收」，或在聊天发送「查看压铆件验收清单」。清单记录精确型号、实际库文件版本、目录底孔、试板实测孔径、安装参照和原生装配回执。族表重名使用完整型号。

只有当前型号及库件文件的 SHA256 与验收记录相同，MWEAI 才会优先使用该次验收的定位圆柱和承压面。执行时仍读取当前 Creo 装配中的真实孔壁及板面，并核对朝向、承压区和实际约束。目录标注的孔径经该规格的定位、承压面和实装核对后，才用于默认孔径。库中未标注底孔时，清单中的试装孔径用于复现验收样件。

如需恢复前一版，在保存并正常退出对应的 Creo 会话后，从本机 MWEAI 管理器回退，再重新打开 Creo。



## 在对话里装压铆件

在活动装配选中安装面或目标孔后，发送「装 M4 压铆螺母」或「装 BSO M3×8」。指定「这六孔各装一颗 M4 压铆螺母，型号和方向你定」可在孔组和安装面唯一时自动选择。插件读取已登记公司库，先核对规格、安装孔径、板厚和定位面，再为每颗紧固件写入同轴和端面定位并读回。孔径不适配时会显示当前孔径及该规格需要的尺寸。


## 一句话装配具体规格

进入目标装配，选中安装面和目标孔，发送「装配bsoM3X8」。也可说「装配bsoM3X6」「安装 BSOS M3×8」或直接给出已验收的完整型号。当前安装面已选时，可用「装配6个bsoM3X8」指定孔数。MWEAI 在 Creo 内读取已登记公司库、核对实际族表实例和安装尺寸，再写入并读回同轴与端面约束。装配模型按原有保存规则留在会话里。

只有系列名时，MWEAI 会问螺纹和长度。若有多个可用安装面、多个候选孔组，或本机没有该精确规格，回执会说明要补充的信息。现有模型按照实际验收结果继续使用。

在独立 Creo 会话可用拷贝的测试装配检查库的具体实例、孔径、轴线、贴合和再生。需要回退此版本时，可从 MWEAI 版本管理恢复 0.23.0-local.workflowrepair.1，保存工程后正常重启 Creo。

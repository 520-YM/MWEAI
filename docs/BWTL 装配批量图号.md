# MWEAI 装配批量图号

打开目标总装或子装配的独立 Creo 窗口。在「仿照模型 → 批量处理」选中对应指令，会填入聊天输入框。先查看模型树和属性，再按用户指定的类别安排编号。

| MWEAI 聊天指令 | 行为 |
| --- | --- |
| `查看装配图号` | 按 Creo 特征树递归列出组件实例路径、模型名、`CNAME` 和 `CINDEX`。每页 16 条，下一页可发送 `查看装配图号 16`。 |
| `预览批量图号 M26A1481 V00 1 ID:42 MAKE "摄像头支架" ID:43 KEEP -` | 从序号 `001` 起查重。按模型在树中首次出现的顺序，为明确列为 `MAKE` 的自制零件或子装配准备图号。`CNAME` 取引号内的中文名，`CINDEX` 取分配的新图号。`KEEP` 用于明确保留紧固件、外购件和其他组件。 |
| `应用批量图号 DN-…` | 将预览中给出的标识原样发送。在同一 Creo 会话中核对预览的目标和最新读回，通过后应用一次。 |

一次预览最多接收 8 条组件路径。嵌套实例使用 `ID:44/57` 这样的路径。同一模型装入多个位置只分配一次图号，原实例路径和数量保持。若两个路径指向同一模型，请为两条指定同一处理方式和同一名称。未列出的组件一律保持原样。

预览会读当前 E 盘 Creo 项目目录和同一会话内的模型、装配、工程图，跳过已经占用的三位序号。前缀包含确定的年份、设计者、项目流水和类别，版本采用 `V00` 这样的两位数格式。分配只核对当前目录及 Creo 会话，跨项目或企业总账发号仍按公司的工程流水管理。

应用支持可修改且尚未保存的本地自制件或子装配。已经采用同一公司图号的装配和零件，应使用现有配套图号功能一起改名。骨架、族表零件、外部父参照、抑制或不可读的装配实例和已保存的组件需要先核对。全部写入前检查名称、引用、参数与项目路径，依次改名和写入，随后读取原生图号、参数、实例标识、位姿与约束数量。写入中途失败会恢复并核对原结果。完成后修改保留在当前 Creo，使用正常保存流程保存。

## Codex 本机联动

通过当前 MWEAI 安装的 `Invoke-BWTL.ps1` 获取 `-Action Status` 回执，然后将该会话返回的 `context` 提供给 `-ExpectedContext`。`-Command` 使用 `DRAWING_NUMBERS AUDIT`、`DRAWING_NUMBERS PREVIEW ...` 或 `DRAWING_NUMBERS APPLY ...`。审计和预览使用 `-Action Read`，应用使用 `-Action Execute`。预览、应用必须绑定同一个 Creo 进程和装配；应用后再次获取状态，再用审计核对结果。

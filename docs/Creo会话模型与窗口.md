# Creo 会话模型与窗口

在 BWTL 聊天框发送以下指令即可操作当前 Creo 进程中的装配和零件。

| 指令 | Creo 实际操作 |
| --- | --- |
| 读取会话模型与窗口清单 | 列出会话中的 ASM 和 PRT，显示独立窗口 ID、活动状态和未保存改动。仅加载到内存的模型也显示在清单中。 |
| 回到 AI_ASM_261119_133845_1V00.ASM | 激活指定的装配。即使其他 PRT 与它同名，仍按 ASM 类型核对。 |
| 激活模型窗口 窗口 ID 1001 | 按清单返回的实际窗口 ID 激活。 |
| 激活模型窗口 FRAME.ASM | 模型已加载且没有独立窗口时，为该模型打开独立窗口。 |
| 读取装配树 | 读取活动装配里的原生组件实例及状态。 |
| 回到装配 FRAME.ASM，然后读取装配树 | 确认活动窗口后，读取该装配的树。 |

回到本轮父装配仍可发送「回到父装配」。在独立零件中发送「回到装配体」或「回总装」时，如果只有一个已打开的装配，BWTL 会切到那个装配。有多个则显示名称和窗口 ID。明确指定名称时，切换可跨独立零件和已有装配。若同名 ASM 与 PRT 同时存在，可以用后缀或窗口 ID 明确目标。

切换前核对源窗口、模型身份和版本。切换后核对 Creo 实际活动窗口，再刷新目标快照。导航保留原窗口、未保存改动和工作目录。它只访问当前进程中已加载的模型。

独立 Creo 验收使用同号 ASM 和 PRT、带未保存首壁的独立钣金件和一个只有内存模型的装配。验证了明确装配切换、装配树读回、无窗口模型打开、按窗口 ID 返回、同名提示以及前后模型版本和磁盘文件一致。需要回退时在保存工作并正常退出对应 Creo 会话后，通过该 BWTL 安装根目录的 `BWTL-Manage.exe -Rollback` 恢复上一版本。

# MWEAI 钣金价格

在主窗第二行「钣金DFM」右侧打开「钣金价格」。可手动输入，或读取活动 Creo 零件与装配的 X/Y/Z 包络作为 W/D/H 参考。核对朝向，填写外壳净重、订单名称、负责人、材料和数量，并确认是否计喷涂。

计算使用用户提供的玛威尔便携包原始 compute_cost.py。材料单价、工时、损耗、加工面积和喷涂计算口径见 resources/sheet-metal-price/default-rates.md。计算只提供内部估算预览，当前页面没有台账登记入口。若另外授权登记，先在 Codex 中依照成本估算技能确定标准 Excel 台账位置。

安装包使用本机已配置的 Codex 工作区 Python。resources/sheet-metal-price/python-path.txt 记录本机可执行路径，环境更新后若路径失效，应改为已安装的兼容 Python。计算不依赖 STEP 解析器或 Excel。通过安装管理可回退至 .26。
计算成功后，「导出数据」将本次输入、材料与加工费用、喷涂、单台价和订单总价写入 Creo 当前 E 盘工作目录。导出为带 BOM 的 UTF-8 CSV，可用 Excel 打开。输入一旦修改，需重新计算后才能导出。每次导出创建新文件，保留已有报价。可通过安装管理回退至 .28。
「打开数据文件夹」位于「导出数据」左侧。优先打开本次会话最近一次成功导出的目录，尚未导出时使用当前可用的 E 盘 Creo 工作目录。可通过安装管理回退至 .30。

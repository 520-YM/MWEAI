# MWEAI 0.23.0-preview.9

BWTL 更名为 MWEAI。打开 Creo 后在 MWEAI 选项卡启动助手。已有用户在原安装位置升级，聊天记录、建模规则、学习记忆及公司标准仍从原数据目录读取。

## 安装与核对

1. 下载 MWEAI-Setup-0.23.0-preview.9.exe 或 MWEAI-0.23.0-preview.9-windows-x64.zip，对照同页 SHA256SUMS-0.23.0-preview.9.txt 校验文件。
2. 在安装界面选择本机 Creo 和数据盘。升级时选择原有安装目录。
3. 保存手中的模型并正常退出对应的 Creo 会话，下次打开可在 MWEAI 标签和聊天窗口看到新名称。可在「标准文件」查看已有资料。

## 兼容与回退

原数据目录、内部命令标识及 BWTL.dll 继续使用已有标识，以便从历史版本升级。需要恢复旧版本时，在安装管理中选择「回退上一版本」，随后正常重新启动 Creo。历史标签和发行附件按各自发布时的名称保留。

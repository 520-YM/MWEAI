# 压铆件选型与验收查询

在 BWTL 聊天输入「查询压铆件验收 BSO M3X8」，查看当前库件版本、压铆件类型、已有 Creo 试装依据、定位圆柱和承压面。输入「查看压铆件验收清单」打开完整验收表。输入「刷新压铆件目录」核对登记目录并清除本会话的文件指纹缓存。

BSO M3X5、M3X6 和 M3X8 沿用公司 3.5 系列映射。BSOS M3X8 使用 BSOS 同规格。BSO M4X8 与 BSO 3.5 M4X8 是不同族表，BSO_M3X5 也可以用精确件号单独指定。Creo 索引不可用时，已经验收、源文件一致的型号仍可定位并核对原生实物行。其他型号可使用「族表名:实例名」直接核对。发现重名时请使用完整规格。

按实测孔径和板厚选型时，BWTL 核实当前库件版本及公司目录标注的底孔。存在多个等厚试装规格时会列出选项。指定规格无对应孔径时，给出最近有依据的候选底孔或仅作 Creo 试装的候选规格。已登记目录的底孔尺寸、Creo 试板尺寸和实体定位段尺寸分别显示。公司目录未记录最小板厚、孔径公差或压铆工艺，试装记录仅证明该型号在对应 Creo 试板上的原生装配、保存及重开结果。

在明确决定以后使用的公司型号后，可输入「保存压铆选型 S-M4-1」。保存结果会给出 E 盘路径、适用孔径和板厚。下次委托选型时，只有现行库件指纹、公司底孔、实际孔径、试装板厚及所要求的螺纹和类型同时匹配，才可进入实际定位核对。

在独立 Creo 验证时，使用一份无索引的库副本查询 S-M4-1，核对仍能读到原生族表行。随后核对同孔径有多个规格时保留模型、显式保存一款后重新选型、板厚变化不沿用，以及目录刷新后仍按新文件核对。原生定位及实际放置另有回执。

回退可在本机 BWTL 管理程序选择上一已备份版本。目录查询与选型仅从登记的公司库读取。明确保存的选型文件位于 BWTL 数据目录的建模规则\装配经验内，可随其他公司规则备份。

# BWTL 图号接续与成对改名

图号沿用公司标准的年份、识别码 A、由工程确认的两位年度流水和零件类别 81。新版从同一 E 盘项目已核对的 Creo 总装读取工程流水，在本机项目目录与当前 Creo 会话检查 81 类序号。历史版本的 ASM、PRT、DRW 也占用已使用的序号。多个 BWTL 进程在同一工作目录分配时，各自保留当前 Creo 会话的占位文件。正式登记以公司的工程台账为准。

在项目中创建总装并明确给出已经分配的图号。也可以打开 E 盘同一工作目录里的最新已保存总装。随后在 BWTL 中发送「创建一个零件」，会建立同图号的 ASM 和空钣金 PRT。可以直接问「刚才建的图号是多少？」。

如果刚才建的是临时图号，确认处于对应项目后，可以发送「把刚才那个图号改成正确的」。紧接着讨论图号时，也可以说「那就帮我改成正确的」。插件从本次 Creo 会话的创建回执找回同号装配、钣金件和组件 ID，核对工程流水、图号占用和上级引用，再执行成对改名并回读原装配位置。如果原图号已经符合当前项目，会回报同一个图号。想指定版本时，可以发送「把刚才那对图号改成 M26A1481001V01」。

成对原生改名适用于本次 Creo 会话里由 BWTL 记录的未保存模型。已保存的配套项目件需要先核对磁盘上的上级装配和工程图引用。发生改名失败时回读两份原名和模型关系，核对通过后才可以继续其他写入。本功能的改名回执会显示 Creo 会话状态，项目文件由用户按工作流程保存。

验收覆盖同号建件、即时图号回读、数字查重、成对改名、项目总装身份和原实例读回。第一次独立验收中，测试候选的装配返回函数误传裸组件 ID，触发了测试进程回溯。已改用标准实例路径，后续独立验收复核组件 ID 和两份模型身份。

需要回退时，请保存 Creo 工作后，通过 BWTL 管理工具选择上一已安装版本 0.23.0-local.aidrawingworkflow.1。项目文件和任务记录存放在 E 盘。

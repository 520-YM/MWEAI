# 模型交付包

在 BWTL 聊天框中输入 **给当前模型生成交付包。** BWTL 使用当前 Creo 钣金件或装配，生成工程图、制造文件和原生模型包，并回复目录。Creo 工作目录应先切换到 E 盘项目，这台电脑的 BWTL 数据也存放在 E 盘。

- 自定义子目录时，可以输入 **生成交付包 包名样件01。**
- 单个钣金件有多个可用固定面且无法自动确定时，可用 Creo 当前模型的面编号指定 **生成交付包 包名样件01 固定面 SURFACE:159**。
- 钣金件应为健康、单实体且无外部模型依赖。装配须用主表示，装配及所交付的依赖须已保存、来源可核对，其内钣金件须可安全展开。

交付目录包含可编辑的 Creo 原生模型和关联工程图、关联幅面、工程图 PDF、STEP、BOM、制造数据 CSV、可展开钣金件的 DXF 和 SHA-256 清单。装配提供层级 BOM 和采购 BOM，按不同模型分别输出钣金展开。制造数据从 Creo 实际几何和展开文件读取。若未填写图号或版本，表格保留空值。

工程图是校对稿。本机配置的 A3 图框可能包含公司名或图号占位符、与实际纸张设置不同的固定幅面文字，长型号也可能超出标题栏。交付前应核对投影、标题栏和实际幅面，补齐尺寸、公差、技术要求及签审。装配图模板没有关联视图时，BWTL 会生成并检查三张模型关联视图。配置模板不可用时，BWTL 可尝试 Creo 通用 A3 模板，并在清单记录实际模板和设置警告。

生成时先写入同一工作目录下的临时子目录，通过核验后再提交独立交付目录。同名目录会阻止覆盖。完成后恢复当前活动模型和工作目录。如有失败，BWTL 会回复失败阶段。可将完整交付目录复制到另一个项目后，从其中重新打开 Creo 工程图核对模型和引用；文件完整性可按清单中的字节数和 SHA-256 复核。

Creo 10.0 的独立会话已验证带孔钣金平板、装有该钣金件的装配和两折弯 U 形件。已用另一个 Creo 进程从交付目录重新打开平板和装配的工程图，并核对关联模型从交付目录读取。回退使用 BWTL 的版本管理恢复上一版。已经生成的交付目录可保留在各自项目中。
